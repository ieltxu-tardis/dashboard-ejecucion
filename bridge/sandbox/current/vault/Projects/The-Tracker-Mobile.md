# The Tracker Mobile

## Goal
Deliver a focused Phase 1 mobile companion for The Tracker (RyzLabs roles first) with fast pipeline visibility and quick actions.

## Scope (Phase 1)
- Auth + RBAC
- Home KPIs/alerts
- Candidates list + detail
- Kanban stage change
- Roles list + detail
- Talent pool summary
- CRM funnel + follow-up reminders (light actions)
- Activity timeline + notifications
- Shared board public view (if required)

## Out of Scope
- Creation workflows, admin/system settings, finance approvals, IT device management.
