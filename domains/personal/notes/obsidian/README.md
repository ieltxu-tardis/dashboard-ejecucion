# Obsidian Pack (Tardis)

Este pack está listo para copiar/enlazar a tu vault.

## Incluye
- templates/daily-am.md
- templates/daily-pm.md
- templates/persona-handoff.md

## Uso
1. Crear nota diaria con AM al comenzar.
2. Cerrar con PM.
3. Usar handoff template cuando Tardis delega a builder/scout.

## Nota técnica
`obsidian-cli` en este host requiere `OBSIDIAN_API_KEY` para operar vía API.
Mientras tanto usamos flujo file-first (markdown plano) compatible con vault.
