# CLAWVAULT_PILOT_PLAN.md

## Objetivo
Validar si ClawVault aporta valor real al sistema actual sin agregar fricción innecesaria.

## Alcance del piloto (shadow mode)
- Duración: 4 días
- Modo: local-only, sin API keys, sin hooks automáticos invasivos
- El sistema actual sigue siendo la fuente principal de operación

## Criterio de éxito (GO)
- Menos pérdida de contexto en handoffs
- Mejor recuperación de decisiones pasadas
- Menos retrabajo por falta de memoria
- Costo operativo aceptable (complejidad y mantenimiento)

## Criterio de descarte (NO-GO)
- Fricción alta para el flujo diario
- Señal duplicada/ruidosa sin valor
- Sin mejora visible frente al sistema actual

## Entregable final
Informe claro: `GO / DEEPEN / DISCARD` con evidencia concreta de impacto positivo/negativo.
